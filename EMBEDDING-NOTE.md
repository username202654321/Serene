# Serene embedding

Serene keeps web destinations inside its Browser and Web Apps surfaces with normal same-page iframes where the destination permits embedding.

Some websites intentionally prevent iframe embedding with their security headers. Serene shows those destinations inside the browser surface without silently opening a separate tab, and provides an explicit external-open action when needed.

A proxy engine such as MercuryWorkshop Scramjet should only be connected to infrastructure and destinations you are authorized to proxy. This build does not use a proxy to bypass school, workplace, parental, geographic, authentication, or other network access controls.
